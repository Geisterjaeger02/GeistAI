GeistAI

A voice assistant that lives on your own network. Install it on your device right here in the browser.

Ein Sprachassistent, der in deinem eigenen Netzwerk lebt. Installiere ihn direkt hier im Browser auf dein Gerät.

Choose your deviceWähle dein Gerät

Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. Dein Browser kann nicht mit USB-Geräten sprechen. Öffne die Seite in Chrome oder Edge am Computer. Installing only works over https. Installieren geht nur über https.

How it worksSo geht's

  1. Plug the device into this computer Gerät an diesen Computer anschließen

    Use a USB-C cable that carries data, not a charge-only one.

    Nimm ein USB-C-Kabel, das Daten überträgt, kein reines Ladekabel.

  2. Click Install and pick the port Auf Installieren klicken und den Port wählen

    The browser lists the device as a USB serial port. Installing takes about a minute.

    Der Browser zeigt das Gerät als USB-Serial-Port. Das Installieren dauert etwa eine Minute.

  3. Enter your Wi-Fi WLAN eingeben

    Right after installing, the browser asks for your Wi-Fi name and password and sends them to the device over USB. Skipped it? The device opens its own hotspot and shows a QR code you can scan with your phone.

    Direkt nach dem Installieren fragt der Browser nach WLAN-Name und Passwort und schickt sie per USB ans Gerät. Übersprungen? Dann öffnet das Gerät einen eigenen Hotspot und zeigt einen QR-Code zum Scannen mit dem Handy.

  4. Start the GeistAI server on your PC GeistAI-Server auf dem PC starten

    Speech recognition, the language model and the voice run on your own computer. The device finds the server by itself. How to set up the server

    Spracherkennung, Sprachmodell und Stimme laufen auf deinem eigenen Computer. Das Gerät findet den Server von selbst. So richtest du den Server ein

Already running GeistAI? Connect it and click Install to change its Wi-Fi or update it.

GeistAI läuft schon? Anschließen und auf Installieren klicken, um das WLAN zu ändern oder zu aktualisieren.

Set up the server on your PCServer auf dem PC einrichten

The device is only the face of GeistAI. Listening, thinking and speaking happen on a computer at home. A PC with an NVIDIA graphics card answers fastest, but any 64-bit PC with 8 GB of RAM works.

Das Gerät ist nur das Gesicht von GeistAI. Zuhören, Denken und Sprechen passieren auf einem Computer bei dir zu Hause. Mit einer NVIDIA-Grafikkarte geht es am schnellsten, aber jeder 64-Bit-PC mit 8 GB RAM reicht.

  1. Install Ollama Ollama installieren

    It runs the language model. Download it from ollama.com/download and install it like any other program.

    Ollama führt das Sprachmodell aus. Lade es von ollama.com/download herunter und installiere es wie jedes andere Programm.

  2. Install Python 3.13 Python 3.13 installieren

    Open the Terminal (right-click the Start button) and paste this. Use 3.13, not a newer version: the speech engine doesn't support newer ones yet.

    Öffne das Terminal (Rechtsklick auf den Start-Button) und füge das ein. Nimm 3.13, keine neuere Version: die Spracherkennung unterstützt neuere noch nicht.

    winget install -e --id Python.Python.3.13
  3. Download GeistAI GeistAI herunterladen

    Download the ZIP and unzip it, for example into your Documents folder.

    Lade die ZIP-Datei herunter und entpacke sie, zum Beispiel in deinen Dokumente-Ordner.

  4. Double-click server\setup.bat Doppelklick auf server\setup.bat

    It installs everything (including graphics card support if you have an NVIDIA card) and asks a few things: your town for weather questions, whether answers should also play on the PC's speakers, which voices to download, and optionally an OpenAI key if you want to use ChatGPT. The first run takes 10 to 20 minutes.

    Es installiert alles (auch die Grafikkarten-Unterstützung, wenn du eine NVIDIA-Karte hast) und fragt ein paar Dinge: deinen Ort für Wetterfragen, ob Antworten auch über die PC-Lautsprecher kommen sollen, welche Stimmen geladen werden und optional einen OpenAI-Schlüssel, falls du ChatGPT nutzen willst. Beim ersten Mal dauert das 10 bis 20 Minuten.

  5. Double-click server\start.bat Doppelklick auf server\start.bat

    Wait for “GeistAI is ready - ask away!”. When Windows asks about the firewall, allow access on private networks. Your device finds the server by itself.

    Warte auf „GeistAI is ready - ask away!“. Wenn Windows nach der Firewall fragt, erlaube den Zugriff in privaten Netzwerken. Dein Gerät findet den Server von selbst.

  1. Install Ollama and Python 3.10 to 3.13 Ollama und Python 3.10 bis 3.13 installieren

    Ollama: ollama.com/download. Python: brew install python@3.13 or sudo apt install python3-venv.

    Ollama: ollama.com/download. Python: brew install python@3.13 oder sudo apt install python3-venv.

  2. Download GeistAI and run the setup GeistAI herunterladen und einrichten

    It asks for your town (for weather), the voices and downloads the language model.

    Es fragt nach deinem Ort (fürs Wetter) und den Stimmen und lädt das Sprachmodell.

    git clone https://github.com/Geisterjaeger02/GeistAI.git cd GeistAI/server && ./setup.sh
  3. Start the server Server starten
    ./start.sh
Something doesn't work?Etwas klappt nicht?
The device says “Server not reachable”
The PC and the device must be in the same home network (a LAN cable on the PC is fine, a guest Wi-Fi is not). Allow Python through the Windows firewall on private networks. If it still fails, open Settings → Wi-Fi setup on the device and enter the address shown in the server window, for example 192.168.1.50.
“No module named uvicorn” or “cannot be loaded because running scripts is disabled”
Always start GeistAI with start.bat, not by typing commands into a new window.
“cublas64_12.dll not found”
The graphics card support is incomplete. Run setup.bat again. Until then GeistAI uses the processor, which is slower but works.
An error about ctranslate2 during setup
Your Python is too new. Install Python 3.13 (step 2) and run setup.bat again.
No voice
Devices without a speaker (StickC Plus2, or a T-Embed with its speaker removed) show the answer as text. To hear it on the PC, run setup.bat again and answer “y” to playing answers on the PC.
The weather is for the wrong place
Run setup.bat again and enter your town, or name the place in your question.
Das Gerät zeigt „Server nicht erreichbar“
PC und Gerät müssen im selben Heimnetz sein (LAN-Kabel am PC ist okay, ein Gast-WLAN nicht). Erlaube Python in der Windows-Firewall für private Netzwerke. Klappt es trotzdem nicht: Auf dem Gerät Einstellungen → WLAN einrichten öffnen und die Adresse aus dem Server-Fenster eintragen, zum Beispiel 192.168.1.50.
„No module named uvicorn“ oder „Ausführung von Skripts ist deaktiviert“
Starte GeistAI immer mit start.bat und nicht mit Befehlen in einem neuen Fenster.
„cublas64_12.dll not found“
Die Grafikkarten-Unterstützung ist unvollständig. Starte setup.bat noch einmal. Bis dahin nutzt GeistAI den Prozessor, langsamer, aber es funktioniert.
Fehler mit ctranslate2 bei der Einrichtung
Dein Python ist zu neu. Installiere Python 3.13 (Schritt 2) und starte setup.bat noch einmal.
Keine Stimme
Geräte ohne Lautsprecher (StickC Plus2 oder ein T-Embed mit ausgebautem Lautsprecher) zeigen die Antwort als Text. Damit du sie am PC hörst: setup.bat noch einmal starten und bei „Antworten am PC abspielen“ mit „j“ antworten.
Das Wetter ist für den falschen Ort
setup.bat noch einmal starten und deinen Ort eingeben, oder den Ort in der Frage nennen.
